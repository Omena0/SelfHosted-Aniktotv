# Screenshots Guide

## How to Add Screenshots

1. **Take screenshots** of these pages:
   - `homepage.png` - Homepage with Continue Watching & Airing Schedule
   - `local-library.png` - Local Library page showing your anime collection
   - `anilist-library.png` - AniList Library sync page
   - `settings.png` - Settings/Notifications page

2. **Save them** in this folder with the exact names above

3. **Recommended size:** 1920x1080 or 1280x720 (16:9 aspect ratio)

4. **Format:** PNG or JPG (PNG preferred for better quality)

5. **After adding**, commit and push:
   ```bash
   git add screenshots/
   git commit -m "Add screenshots"
   git push
   ```

The README.md will automatically display them in a 2x2 grid!
